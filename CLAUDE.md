# Client Ops Command Center

Public work sample prepared by Ankit Mishra for a Head of Operations & Customer Success application. All data is synthetic. Not affiliated with or endorsed by CanadaVisa or Cohen Immigration Law. See README.md.

## Working rules

- App lives in `app/`: `cd app && npm ci && npm run generate && npm run typecheck && npm test && npm run build`.
- Classifier, SLA, routing, draft templates and guardrails live in `app/src/lib/classify.ts` and `app/src/lib/routing.ts`; change the rule and its test together.
- Data is generated by `app/src/lib/generate.ts` and `app/src/lib/hiring.ts`; the committed JSON must match the generator byte for byte (tested).
- Every page carries the prototype banner from `app/src/lib/brand.ts`. Never use the firm's logo, colours or site content.
- Vercel project root directory is `app`.
